# 2026_Solubility-Profiling-of-Therapeutic-Peptides-by-Taylor-Dispersion
Contains the basic code for analysing in-capillary protein precipitation taylorgrams. The full dataset can be found at https://doi.org/10.5281/zenodo.20545312, but this code may need modification of initial fit parameters to appropriately fit all the available data. Manual inspection of the output is advised.
